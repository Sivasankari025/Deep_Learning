# AI Art Studio: Photo to Painting

## Project Overview
AI Art Studio is a deep learning mini-project that transforms an input photograph into an artistic painting using Neural Style Transfer.

## Technologies Used
- Python
- Google Colab
- PyTorch
- VGG19 pretrained CNN
- PIL and Matplotlib

## Model
The project uses VGG19-based Neural Style Transfer to preserve the content of an input image while transferring artistic patterns and textures from a style image.

## Features
- Upload a content image and a style image
- Generate a stylized painting
- Adjust style strength
- Optional image sharpening
- Save the output as a PNG image

## How to Run
1. Open `DL_miniproject.ipynb` in Google Colab.
2. Run the notebook cells in order.
3. Upload a content image and a style image.
4. Generate and save the stylized output.

## Expected Output
An artistic version of the original photograph that preserves its main content while applying the selected painting style.
